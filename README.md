# Gem Accessories — Enter the Boutique

A fully static concept experience built around a scroll-driven door reveal and an interactive glass product wheel. Product photography comes from the public `@gem__accessories_` Instagram research archive; working names and featured order require owner approval.

## Local development

```bash
npm install
npm run dev
```

## Production check

```bash
npm test
```

The build output is written to `dist/`. Asset URLs use Vite's base path so the same build can run at a GitHub repository subpath. The included Pages workflow is intended for a non-transactional concept/demo; choose a host whose terms permit commercial storefronts before turning it into a live shop.
